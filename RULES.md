RULES:
1. Sentence case every scope line: capitalize the first word, and after that capitalize ONLY proper nouns, brand names, and acronyms from rule 2. Everything else stays lowercase.
   - "Furnish and install shower door"
   - "Demolish existing tile shower"
   - "Install green board on shower surround"
   Do NOT capitalize ordinary construction words: shower, vanity, toilet, joists, blocking, niche, subfloor, drywall, green board, tile, flooring, baseboard, framing, plumbing.
   Do NOT capitalize room and area names — they are common nouns, not proper nouns: bathroom, master bathroom, half bath, kitchen, bedroom, master bedroom, laundry room, utility room, basement, garage, hallway, closet, linen closet, mudroom, entryway, shower surround, wet area.
   - "Install new vanity in master bathroom"
   - "Demolish existing tile in guest bathroom"
   - "Furnish and install LVP flooring in kitchen and hallway"
   (Job NAMES are different — those are titles and stay title case, e.g. "Doreen Kruger Master Bathroom". This rule is only about scope lines and notes.)

2. ALWAYS-CAPITALIZED TERMS — preserve these exactly, anywhere in the line:
   - Brands: Moen, Delta, Kohler, Sterling, Schluter, Hardie, HardieBacker, Wedi, Kerdi, DensShield, Durock, Sheetrock, Posi-Temp, Bootz, Mansfield, Toto, American Standard
   - Acronyms: LVP, LVT, OSB, MDF, PVC, ABS, CPVC, PEX, GFCI, CDX, TP, ADA, R-13, R-19
   - Anything else that is plainly a brand or model name, even if not listed here. Never lowercase a product or model name.
   Correct: "Install new Moen shower valve trim and shower head (chrome)"
   Correct: "Install owner provided LVP flooring"
   Wrong:   "install new moen shower valve", "install owner provided lvp flooring"

3. Fix missing small words that speech-to-text drops — "and", "the", "to", "of" — only when their absence is clearly a mishearing of natural speech.

4. Apply these exact phrase corrections (note the sentence-case forms):
   - Any variation of "furnish and install" → "Furnish and install" at the start of a line, "furnish and install" mid-line
   - "install on provided" / "install owner provide" / "install homeowner provided" → "Install owner provided"
   - A line starting with "Owner provided" (no Install at the front) → add "Install" at the start
   - "owner to pay electrician" / "owner pay electrician" → "Owner to pay electrician directly"
   - "owner to pay plumber" / "owner pay plumber" → "Owner to pay plumber directly"
   - "remove and replace" / "remove replace" → "Remove and replace" at the start of a line, lowercase mid-line
   - "LMP", "LBP", "LBV", "LVB", or any similar 3-letter combo → "LVP" (only when the line is about flooring)
   - "dura rock" / "dura-rock" / "durarock" → "Durock"
   - "green board" → "green board" (lowercase — it is a material, not a brand)

5. CONSTRUCTION TERM MISHEARING CORRECTIONS — read the FULL LINE in context before applying any of these. If the substitution would make the line nonsensical, leave the original word:
   - "Joyce" or "Joyce's" → "joists" or "joist" — ONLY when the line is clearly about structural framing: floors, ceilings, subfloor, sistering, ledger, rim, headers, or similar structural context. Example: "Sister the Joyce in bathroom floor" → "Sister the joists in bathroom floor"
   - "Furnishing" at the start of a line → "Furnish and" — Example: "Furnishing install new toilet" → "Furnish and install new toilet"
   - "Sheetrock" (any case) → "Sheetrock" (brand name, stays capitalized)
   - "OSB" → keep as "OSB" (do not spell out)
   - "LVP", "LVT" → keep as-is (these are correct flooring acronyms)

6. MEASUREMENT NOTATION — only when a number is clearly a physical dimension (lumber size, length, width, height, depth, on-center spacing), convert spoken-out dimensions to standard shorthand:
   - "two by four" / "Two By Four" → "2x4" — numbers joined by a lowercase "x", no spaces. Applies to any count: "two by six by eight" → "2x6x8"
   - A number followed by "inches" / "inch" → that number followed directly by a straight double-quote, no space: "12 inches" → 12"
   - A number followed by "feet" / "foot" → that number followed directly by a straight single-quote, no space: "6 feet" → 6'
   - Feet-and-inches together: "5 feet 6 inches" → 5'6"
   - Do NOT apply this to phone numbers, addresses, dates, or counts of items ("2 boxes", "3 outlets") — only physical dimensions.

7. DO NOT reword, restructure, or add words beyond what the rules above specify.

8. DO NOT change product names, brand names, model numbers, or the underlying value of any measurement — only its notation, per rule 6.

9. If a word seems like a mishearing but none of the corrections above clearly apply, leave it exactly as-is. Never guess.

10. Dictation usually arrives already correct. Report a line ONLY if you actually changed it or flagged it. Lines that already follow these rules must be left alone and not echoed back.
